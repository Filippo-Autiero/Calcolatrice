# Calcolatrice

> App Android per eseguire calcoli matematici di base, sviluppata in Java con Android Studio.

---

## Descrizione

Questo repository contiene una **calcolatrice Android** realizzata come secondo progetto personale per approfondire lo sviluppo mobile con Java.
L'app permette di eseguire le operazioni aritmetiche fondamentali attraverso un'interfaccia semplice e intuitiva.

---

## Funzionalità

- Addizione, sottrazione, moltiplicazione e divisione
- Display per visualizzare l'espressione corrente e il risultato
- Gestione degli errori (es. divisione per zero)
- Interfaccia grafica con pulsanti numerici e operatori

```

├── settings.gradle.kts    # Impostazioni del progetto

```

---

## Come eseguire il progetto

1. **Clona il repository:**
   ```bash
   git clone https://github.com/FilippoAutiero007/Calcolatrice.git
   ```
2. **Apri il progetto** in Android Studio (File > Open).
3. **Attendi la sincronizzazione** di Gradle (avviene automaticamente).
4. **Avvia l'app** su un emulatore Android oppure su un dispositivo fisico via ADB.
